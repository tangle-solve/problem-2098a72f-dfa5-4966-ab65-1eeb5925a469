### ALGO-000038: Valiant’s explicit matrix rigidity problem
- **Subfield:** Boolean circuit and formula complexity
- **Open:** Construct an explicit family of \(n\times n\) matrices over a specified fixed field with rigidity \(R_A(\varepsilon n)\ge n^{1+\delta}\) for constants \(\varepsilon,\delta>0\).
- **Status:** Proposed in 1977. Random matrices are highly rigid; achieving the needed parameters explicitly remains open, and several once-promising structured matrices have turned out insufficiently rigid.
- **Type:** theory
- **Why:** Strong explicit rigidity would yield lower bounds for important classes of linear circuits.
- **Key works:** Valiant (1977), *Graph-Theoretic Arguments in Low-Level Complexity*; Ramya (2020), *Recent Progress on Matrix Rigidity—A Survey*, arXiv:2009.09460.
- **Related:** Coding theory—explicit codes with strong distance properties; compressed sensing—explicit robust measurement matrices.
